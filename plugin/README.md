# jarvis (Claude Code plugin)

Speak your prompts and hear Claude's replies in a refined, JARVIS-style British AI voice.
The voice is an original blend of stock open-source Kokoro voices, run fully offline. It doesn't clone any actor.

- `/jarvis:listen`: speak a prompt (transcribed locally with Whisper)
- `/jarvis:on`, `/jarvis:off`: read replies aloud, or stop doing so
- `/jarvis:hush`: stop talking now

Requires the `jarvis` command from the same repository. Install it with:

    curl -fsSL https://raw.githubusercontent.com/Ashesashu860/jarvis-voice/main/install.sh | bash

See the main README for settings and details: https://github.com/Ashesashu860/jarvis-voice
